# Smart Placement Portal

A Full Stack Placement Management System built using Spring Boot, React, and MySQL.

## Project Status
🚧 Currently Under Development

## Tech Stack

- Java
- Spring Boot
- React.js
- MySQL
- Maven
- REST APIs
- Git & GitHub

## Features

### Student Module
- Student Registration
- View Available Jobs
- Apply for Jobs
- Track Application Status

### Job Module
- Create Job Listings
- Update Job Details
- Delete Jobs
- View All Jobs

### Application Module
- Apply to Jobs
- Prevent Duplicate Applications
- Track Application Status
